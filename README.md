# Emberfall — 10 Car Showroom

Standalone 3D car showroom extracted from the supplied archive. The original project and archive are unchanged.

Open `showroom.html` or the site root. Includes all ten cars, camera views, paint colors, finishes, auto-rotate, wireframe, and lighting controls.

The `docs/` directory contains the ready-to-host site, including its bundled Three.js dependency. GitHub Pages should serve the `main` branch, `/docs` folder.
